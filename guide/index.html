# 苹果手机拍照设置

# 2023/10/8/10.23

💫光圈 光圈值以f表示，数值越小，虚化效果越大。 iPhone的光圈大小是通过系统计算模拟的，所以在拍摄完成后，可以在相册中编辑修改光圈大小，得到满意的虚化效果。

💫曝光补偿 向右调整，数值增加变亮； 向左调整，数值减小变暗。 拍人像建议增加0.7，使皮肤更透亮一点。

💫色温 向右调整，数值增加画面变黄； 向左调整，数值减小画面变蓝。 在iPhone的拍摄模式中选择冷色调，可以达到人像冷白皮的效果。

💫焦距 iPhone13仅配置了一个广角镜头和一个标准镜头，没有长焦镜头。远距离的拍摄都是通过剪裁来完成，所以我们选择焦距的时候，不要选太大的倍数，会造成画面模糊，1.5倍左右就可以了。

💫夜景模式 最长可以选择30秒曝光，需配合三脚架使用。

💫实况模式 开启实况模式拍摄的照片，进入相册下拉实况选项，选择长曝光，可以得到一张流水拉丝的照片。

💫HDR 在设置➡️照片中关闭HDR，可以修正iphone13人像的过度锐化，不做抠图假人。 HDR适用于拍摄最亮和最暗部分相差特别大的环境，多用于拍摄风景。HDR开启后会连拍三张照片，分别对应欠曝光、正常曝光和过度曝光，然后把这三张图片合到一块并且突出每张照片最好的部分从而生成一张精妙绝伦的照片。

💫设置 “格式”➡️选择“兼容性最佳”为Jpeg格式，画质比高效更好。iPhone12/13 Pro以上机型，还可以选择raw格式，无压缩更利于后期处理。

“保留设置”➡️“曝光调整”开启，始终显示曝光调整指示器。

“使用调高音量建连拍”开启，方便抓拍。

“网格”开启，辅助构图。

“镜像前置摄像头”开启。

“优先快速拍摄”关闭，关闭智能调整图像质量。

“镜头校正”开启。
